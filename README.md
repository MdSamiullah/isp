# ISP Manager — public demo

This is a **demonstration** of an ISP management app, running entirely in your browser with **synthetic data**. It has no server, no real customers, no real payments and no connection to any network equipment. Changes you make stay in your browser and can be reset.

Use the "View as" switch to see the app as an administrator, a staff member or a subscriber. The switch is a demo control, not a login.

This repository contains only the generated demo files. It is published automatically; please don't open pull requests that edit these files directly.
